# Duke Chatbot Groq AI

Bot percakapan sederhana berbasis Python yang terintegrasi dengan API Groq untuk pemrosesan bahasa alami secara cepat.

## Fitur Utama

- Respon cepat menggunakan infrastruktur Groq AI.
- Pengolahan prompt berbasis Python.
- Ringan dan gampang dikustomisasi.
